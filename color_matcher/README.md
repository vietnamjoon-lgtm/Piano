# 정답 색 맞추기 자동 도우미

핀은 가운데 고정, 판을 끌어서 움직이는 게임용이에요.
'정답' 색을 읽고 판에서 같은 색 위치를 찾아 그 지점을 잡고 핀 끝까지 끌어다 놓아요.
'선택' 칸 색을 다시 확인해서 어긋나면 화면을 새로 찍어 다시 끌고, 핀 끝 위치 오차도 스스로 보정해요.

## 설치 (Windows)
    pip install mss numpy pyautogui

## 1) 처음 한 번: 위치 지정
게임 창을 띄워 두고:

    python color_matcher.py --setup

안내에 따라 마우스를 **정답 칸 → 선택 칸 → 판 왼쪽 위 → 판 오른쪽 아래 → 핀 끝** 위에
차례로 올리고 콘솔에서 Enter. (게임 창을 옮기면 다시 해야 해요)

## 2) 실행
    python color_matcher.py

정답 색이 바뀔 때마다 자동으로 맞춰요. 라운드마다 콘솔에 시도 결과와 걸린 시간이 찍혀요.

## 잘 안 맞을 때
    python color_matcher.py --debug

같은 폴더에 `log.txt`(시도마다 기록)와 `debug` 폴더(끌기 전/후 판 화면)가 생겨요.
빨간 + 는 찾은 정답 위치, 초록 + 는 핀 끝이에요. 이걸 보내 주면 원인을 알 수 있어요.
로그에 "판이 안 움직였어요"가 나오면 cmd를 **관리자 권한으로 실행**하세요.

## 멈추기
콘솔에서 Ctrl+C, 또는 마우스를 화면 **왼쪽 위 모서리**로 휙 옮기면 비상 정지.
